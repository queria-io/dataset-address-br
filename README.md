# アドレス・ベース・レジストリ

デジタル庁の[アドレス・ベース・レジストリ](https://dataset.address-br.digital.go.jp/)の、都道府県・市区町村・町字のマスタと、住居表示の街区・住居、地番のマスタを、SQL で検索・集計できるテーブルにしたデータセットです。それぞれ代表点の座標を持ち、住所の正規化やジオコーディング、町字ごとの集計に使えます。

## 出典と利用条件

- 「アドレス・ベース・レジストリ」（デジタル庁）の各マスタデータと位置参照拡張を加工して作成しています
- アドレス・ベース・レジストリの利用規約に従います

## テーブル

| テーブル | 内容 | 行数 |
| --- | --- | ---: |
| `main.mart_pref` | 都道府県マスタ | 47 |
| `main.mart_city` | 市区町村マスタ（政令指定都市は市と区の両方の行） | 1,918 |
| `main.mart_town` | 町字マスタ（大字・町・丁目・小字） | 727,396 |
| `main.mart_rsdtdsp_blk` | 住居表示の街区マスタ（「1番」） | 924,884 |
| `main.mart_rsdtdsp_rsdt` | 住居表示の住居マスタ（「3号」） | 21,984,788 |
| `main.mart_parcel` | 地番マスタ（「○番地」「○番○」） | — |

テーブルの結合キーは次のとおりです。

- 町字: `lg_code`・`machiaza_id`
- 街区: 町字のキーと `blk_id`
- 住居: 街区のキーと `rsdt_id`・`rsdt2_id`
- 地番: 町字のキーと `prc_id`

`lg_code` は 6 桁（チェックディジット付き）なので、lg_code・zipcode・houjin_bangou と結合できます。5 桁のコードとは `mart_city.lg_code_5` で結合してください。

## 使い方

千代田区の町字ごとに、住居表示の街区の数を出す:

```sql
SELECT t.oaza_cho, t.chome, count(*) AS blocks
FROM address_br.main.mart_town AS t
JOIN address_br.main.mart_rsdtdsp_blk AS b USING (lg_code, machiaza_id)
WHERE t.lg_code = '131016'
GROUP BY ALL
ORDER BY blocks DESC;
```

テーブルは `lg_code` の順に並んでいるので、`lg_code` で絞ると読み込む量が小さくなります。

## 注意

- 住所の「○番」は `blk_num`、「○号」は `rsdt_num` です。地番は本番が `prc_num1`、枝番が `prc_num2`・`prc_num3` です。ほとんどは半角数字の文字列ですが、文字を含む値もあります（「南2」「ア」など）
- 住居表示を実施している町字（`mart_town.rsdt_addr_flg = '1'`）は、街区と住居まで座標を引けます。ただし 6 万 1,375 件のうち 2,322 件は街区の行が無く、町字の代表点までしか引けません
- 住居表示を実施していない町字は、地番を `mart_parcel` で引けます。地番の代表点は一部の筆にしか無く（日野市で 10%、千代田区で 1%）、無ければ町字の代表点までしか引けません
- 町字の代表点は 19 万 7,363 件で、大字・丁目の 9 割にあり、小字にはほとんどありません
- 丁目の表記は市区町村ごとに違います（「１丁目」「三丁目」）。住所の文字列と照合するときは正規化してください。丁目の有無や大字・字の扱いも、照合で表記の揺れが出やすいところです
- `mart_town.wake_num_flg` が 1 の小字では、地番はその小字の中でだけ一意です。小字を省いた地番の住所を大字で検索すると、別の小字の地番に当たることがあります
- 代表点の測地系は元データのままで、変換していません（`mart_town` は JGD2011 と JGD2000 が混在、`mart_rsdtdsp_blk` は JGD2000、それ以外は JGD2011）
- ある時点のバージョンで、廃置分合の履歴は持ちません
